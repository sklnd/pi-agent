# Version Control

- Use `jj` (Jujutsu) instead of `git` for all VCS operations: creating commits, tracking changes, viewing history, branching, etc.
- Never use `git commit`, `git add`, `git branch`, etc. Use the `jj` equivalents.
- Do not default to using worktrees. Only use worktrees when specifically directed to.
- Do not use conventional commit style (e.g., `feat:`, `fix:`, `chore:` prefixes). Write commit messages as plain, descriptive sentences.
